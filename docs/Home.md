## Documentation
### [[Vision]]
The Vision document describes the vision and goals of Crown, including the value it intends to deliver to users as well as the ways it will stand out against existing chess and checkers apps. 
### Assets
The Assets folder includes any necessary asset files which are used in the Crown app itself. This includes app icons, background images, league images, etc. 
### [[Design]]
The Design document explains the design system of Crown, including typography, colors, spacing, icons, animations, cards, buttons, and navigation. 
### UX
The UX folder contains screen behavior specifications. Every screen with a mockup must have a corresponding UX document; implementation contracts may be documented before a mockup is available. 
### Mockups
The Mockups folder houses the image files for UX documents. 
### [[Architecture]]
The Architecture document lays out the technical architecture of Crown, including the app itself as well as backend and data model specification. 
### Specifications
The Specs folder contains the canonical MVP contracts. If another document conflicts with a specification, the specification controls.

Documentation precedence:

1. [[Specs/MVP Scope Matrix]] for inclusion and exclusion
2. Domain documents under Specs for behavior and backend contracts
3. UX screen documents for presentation and interaction
4. [[Architecture]] for implementation overview
5. [[Vision]], [[Design]], and [[Monetization]] for long-term direction
